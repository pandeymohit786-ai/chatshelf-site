FAQ

Questions, answered

Does ChatShelf read my conversations?

No. It reads only the title and link of chats that a site already shows in its sidebar. Message content is never read, stored or sent anywhere.

Which sites does it work on?

ChatGPT, Claude, Gemini, DeepSeek. One folder can hold chats from all of them. More sites may follow based on what users ask for.

Do I need an account?

No. The free version works without signing in, and all your data stays in your browser. An account will only be needed for Pro cloud sync.

How is this different from Projects in ChatGPT or Claude?

Projects only work inside one AI. ChatShelf gives you one folder tree across four AIs, nested folders, a shared prompt library and one search for everything.

What happens when a site changes its design?

If a site update stops the in-page panel from appearing, the side panel keeps working and ChatShelf shows a small notice. We ship fixes through normal extension updates.

Can I back up or move my folders?

Yes. Settings has a one-click export to a JSON file, and import on another browser.

Which browsers are supported?

Chrome and Microsoft Edge (version 116 or newer). Brave and other Chromium browsers should also work. Firefox is planned.

Is ChatShelf made by OpenAI, Anthropic, Google or DeepSeek?

No. ChatShelf is an independent product and is not affiliated with any of them.
